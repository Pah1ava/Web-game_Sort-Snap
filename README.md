# Sort & Snap

A short mobile sorting puzzle. Drag an object into the bin with the matching **shape**. It works with touch, mouse, and keyboard: select the object, then select a bin. Wrong drops return the object with no penalty.

## Game design

- **Goal:** Sort every object into its matching bin.
- **Player role:** Recognize the object's category and place it with one drag or two taps.
- **Level 1:** Six objects; two categories at the start; a third appears after three successful placements.
- **Level 2:** Nine objects with all three categories from the start.
- **Feedback:** Correct drops snap and advance progress. Wrong drops return without a penalty.
- **End:** Completion screen with replay and next-level actions.

The game uses inline SVG shapes and CSS; 
This repository is the playable build.
